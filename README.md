# 🌐 Evolução da Web (1.0 → 4.0) — Site Multi-página

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white)

Site sobre a **evolução da Web**, com uma página para cada fase e navegação entre elas.

## 📄 Páginas

| Arquivo | Conteúdo |
|---|---|
| `index.html` | Sumário |
| `introdução.html` | Introdução |
| `web1.html` | Web 1.0 — a web estática |
| `web2.html` | Web 2.0 — a web social |
| `web3.html` | Web 3.0 — a web descentralizada (blockchain, dApps) |
| `web4.html` | Web 4.0 — a web simbiótica e autônoma |
| `comclusão.html` | Conclusão |

## 🚀 Como executar

Abra `WEBSITE/index.html` no navegador.
